## 总体验收目标

- Node.js 服务可在局域网启动并托管前端与题库资源。
- 单人模式具备配置、答题、计时、生命、跳过、揭晓和结算闭环。
- 多人模式具备 session 身份、房间、抢答、排名、加时和房主离开解散。
- 外部接口模式仅允许一个活动房间，使用玩家昵称提交答案。
- 题库后台以配置密码登录，可编辑题目并按并集导入资源包。
