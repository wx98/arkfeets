# Bilibili 直播弹幕答题

游戏服务端通过本机 [blivechat](D:/workspace/IdeaProjects/blivechat) 的 `/api/chat` WebSocket 接收弹幕。请先启动 blivechat；其默认监听地址为 `127.0.0.1:12450`。游戏浏览器不连接 blivechat，也不会收到身份码。

在 `server/config.json` 中设置：

```json
{
  "bilibili": {
    "blivechatWsUrl": "ws://127.0.0.1:12450/api/chat",
    "roomId": 123456,
    "authCode": "",
    "uidBlacklist": ["10001", "10002"]
  }
}
```

填写 `authCode` 时优先使用身份码；否则使用正整数 `roomId`。身份码模式仍由 blivechat 负责连接 Bilibili 开放平台，必须先在那里配置好开放平台凭据。房间号模式直接通过 blivechat 接入普通直播间。不要将真实身份码提交到公开仓库。

在多人房间创建页选择“直播弹幕”，创建房间后由房主点击“开始抢答”。游戏在确认已连接本机 blivechat 后才开始计时。连接断开时页面会显示重连状态，期间不接收答案，后台每 3 秒重试。房主离开或排名开始时停止接收，回到等待室会移除直播观众。

只处理普通文字弹幕：以 UID 作为唯一身份、昵称作为显示名、文字内容作为答案；判题忽略大小写和首尾空格。图片表情、礼物、舰长、醒目留言、镜像消息及无 UID 消息均不参与。彩色文字弹幕仍按普通文字处理。同一条消息 ID 只处理一次。

`uidBlacklist` 可以在游戏运行时直接修改。每条文字弹幕到达时都会重新读取该列表，无须重启游戏或 blivechat；配置文件暂时无法解析时，这条弹幕会被拒绝。
