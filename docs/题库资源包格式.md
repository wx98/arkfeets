# 题库资源包格式

题库资源包是 ZIP 文件。压缩包根目录可以直接放置资源，也可以包一层目录，但只能包含一个 `catalogue.json`。

## 目录结构

```text
arkfeets-questions/
├─ catalogue.json
├─ full_data/
│  ├─ evidence-wall.png
│  └─ evidence-wall.json
└─ question_data/
   ├─ evidence-wall-01.json
   └─ evidence-wall-02.json
```

- `full_data` 保存唯一的完整原图及同名默认信息。
- `question_data` 每道题一个 JSON 文件。
- 不再使用 `question.png`，也不再维护 `resource/question` 目录。

## Catalogue

`catalogue.json` 是轻量索引：

```json
[
  {
    "id": "evidence-wall-01",
    "file": "question_data/evidence-wall-01.json"
  }
]
```

ID 允许中文、英文字母、数字、点、下划线和连字符，最长 80 个字符。索引 ID、单题文件名和记录内 ID 必须一致。

编辑现有题目时只原子替换对应的单题文件，不重写 catalogue。只有新增或导入题目时才原子更新 catalogue。

## 原图默认信息

每张原图可以维护一个同名 JSON：

```json
{
  "name": "线索墙原图",
  "answers": ["照片墙", "证据墙", "线索墙"],
  "hint": "墙上钉满了调查材料",
  "difficulty": ["simple", "medium", "hard", "hell"],
  "tags": ["场景"]
}
```

该文件只用于从原图新增题目时预填内容，不直接参与游戏判题。新题标题始终为空，维护者必须自行填写并确认裁切。

## 单题记录

```json
{
  "id": "evidence-wall-01",
  "title": "线索集合",
  "answers": ["照片墙", "证据墙", "线索墙"],
  "hint": "墙上钉满了调查材料",
  "difficulty": ["simple", "medium", "hard", "hell"],
  "tags": ["示例", "场景"],
  "originalImage": "evidence-wall.png",
  "question": {
    "x": 215,
    "y": 70,
    "width": 1260,
    "height": 560,
    "sourceWidth": 1672,
    "sourceHeight": 941
  },
  "enabled": true
}
```

`question` 使用原图像素坐标。左上角为 `x/y`，裁切尺寸为 `width/height`，`sourceWidth/sourceHeight` 记录裁切时的原图尺寸。裁切框必须位于原图范围内。

启用题目必须满足：

- 标题非空。
- 至少有一个答案。
- `originalImage` 对应 `full_data` 中存在的图片。
- 裁切坐标完整且合法。
- 难度只包含 `simple`、`medium`、`hard`、`hell`。

## 导入导出

- 导出包包含 catalogue、全部单题 JSON、全部原图和同名默认信息。
- 导入采用并集策略；已有题目 ID 不覆盖，并返回冲突列表。
- 已存在的同名原图和元数据不覆盖。
- 导入前校验索引、记录 ID 和原图引用。
- ZIP 中的绝对路径、盘符路径和 `../` 路径会被拒绝。
- 图片支持 PNG、JPG/JPEG、WEBP 和 GIF；单文件不超过 10 MB，ZIP 不超过 100 MB。
