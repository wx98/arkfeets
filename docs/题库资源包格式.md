# 题库资源包格式

题库资源包是一个 ZIP 文件。压缩包根目录可以直接放置题库，也可以再包一层目录，但只能包含一个 `catalogue.json`。

## 目录示例

```text
arkfeets-questions.zip
└── arkfeets-questions/
    ├── catalogue.json
    ├── operator-amiya/
    │   ├── info.json
    │   ├── question.png
    │   └── full.png
    └── rhodes-kitchen/
        ├── info.json
        ├── question.webp
        └── full.webp
```

`catalogue.json`：

```json
{
  "version": 1,
  "questionIds": ["operator-amiya", "rhodes-kitchen"]
}
```

题目目录名必须与 `questionIds` 中的 ID 完全一致。ID 允许中文、英文字母、数字、点、下划线和连字符，最长 80 个字符，不能包含路径分隔符。

## 题目信息

每个题目目录必须包含 `info.json`：

```json
{
  "title": "示例题目",
  "answers": ["主要答案", "可接受别名"],
  "hint": "可选提示",
  "difficulty": ["simple", "medium", "hard", "hell"],
  "tags": ["干员", "示例"],
  "questionImg": "question.png",
  "answerRevealImg": "full.png",
  "enabled": true
}
```

字段说明：

- `title`（可选）：后台和游戏中使用的题目标题。
- `answers`（必填）：一个或多个正确答案；判定时只忽略全部空白字符。
- `hint`（可选）：答题时显示的提示。
- `difficulty`（可选）：可用难度；省略时应用于全部难度。
- `tags`（可选）：管理用标签。
- `questionImg`（必填）：玩家答题时看到的自行裁切图片。
- `answerRevealImg`（必填）：答案揭晓时显示的完整图片。
- `enabled`（可选）：是否启用，默认 `true`。

图片支持 PNG、JPG/JPEG、WEBP 和 GIF，单张不超过 10 MB。ZIP 不超过 100 MB。

## 导入规则

- 导入结果是现有题库与资源包的并集。
- 已存在的题目 ID 不覆盖，后台会报告冲突列表。
- 新题目必须同时具备有效的 `info.json`、问题图和完整图。
- 导入前会校验整个资源包；格式错误时不会更新 `catalogue.json`。
- ZIP 中的绝对路径、盘符路径和 `../` 路径会被拒绝。

也可以不制作 ZIP，直接在 `server/resource/question` 下按相同结构维护文件；修改后重启服务，或在后台保存任意题目触发重新载入。
